Ankündigungen und FAQs werden auf der **Startseite** des Self-Service-Portals sowie in den jeweiligen Workspaces angezeigt. **Ankündigungen** sind Meldungen, die an das gesamte Unternehmen gesendet werden. Alle Anwenderrollen können Ankündigungen anzeigen, jedoch können nur Anwenderrollen mit entsprechendem Zugriff und Berechtigungen Ankündigungen erstellen. **FAQs** sind Lösungsvorschläge oder Workarounds für allgemeine Fragen. Diese können Sie durchsuchen, bevor Sie einen Incident melden.

**Alarme** sind globale Hinweise, die System- oder Anwendungsfehler (Leistungsprobleme oder Herunterfahren von Anwendungen), Warnungen (z. B. Anwender, die bestimmte Aufgaben nicht durchführen können) und informative Meldungen (z. B. das Verlagern eines Druckers) beinhalten.

Über den Workspace **Suche** können Sie eine Liste aller veröffentlichten FAQs, Ankündigungen und Wissensartikel an einer zentralen Stelle durchsuchen.

<hint type="info">
  Inwieweit Sie Ankündigungen, FAQs und Alarme anzeigen können, ist von den Optionen abhängig, die Ihr Administrator für Ihre Anwenderrolle aktiviert hat.
</hint>

<ExpandableHeading>
  ## So zeigen Sie Ankündigungen an:

  1. Klicken Sie im Workspace-Menü auf **Mehr** > **Ankündigungen**. Eine Liste der Ankündigungen wird angezeigt.
  2. Klicken Sie auf eine Ankündigung, um ausführlichere Informationen anzuzeigen.
  3. Wenn Sie fertig sind, klicken Sie auf **Listenansicht**.

  Um nach einer bestimmten Ankündigung zu suchen, geben Sie ein Stichwort in das Feld **Nach Ankündigung suchen** (oben rechts auf der Seite) ein und klicken Sie auf das Symbol :inlineImage[]{src="https://api.qa.archbee.co/api/optimize/yzXkkCTORWlcwRG_AVHKZ/2O5lsWpqLUOCsANln6FA-_search-icon14x13.png" alt caption} oder drücken Sie die EINGABETASTE. Die übereinstimmenden Suchergebnisse werden angezeigt.
</ExpandableHeading>

<ExpandableHeading>
  ## So durchsuchen Sie alle veröffentlichten FAQs:

  1. Klicken Sie im Workspace-Menü auf **Mehr** > **FAQs**. Eine Liste der FAQs wird angezeigt.
  2. Klicken Sie auf eine Frage, um die Antwort anzuzeigen.
  3. Wenn Sie fertig sind, klicken Sie auf **Listenansicht**.

  Um nach einer bestimmten FAQ zu suchen, geben Sie ein Stichwort in das Feld **Nach FAQ suchen** (oben rechts auf der Seite) ein und klicken Sie auf das Symbol :inlineImage[]{src="https://api.qa.archbee.co/api/optimize/yzXkkCTORWlcwRG_AVHKZ/2O5lsWpqLUOCsANln6FA-_search-icon14x13.png" alt caption}. Die Anwendung zeigt die übereinstimmenden Suchergebnisse an.
</ExpandableHeading>

<ExpandableHeading>
  ## So zeigen Sie Alarme an:

  1. Klicken Sie im Workspace-Menü auf **Mehr** > **Alarme**. Eine Liste aller aktuellen Alarme wird angezeigt.
  2. Klicken Sie auf einen Alarm, um ausführlichere Informationen anzuzeigen.
  3. Wenn Sie fertig sind, klicken Sie auf **Listenansicht**.
</ExpandableHeading>

<ExpandableHeading>
  ## So durchsuchen Sie alle veröffentlichten FAQs, Ankündigungen und Wissensartikel:

  1. Klicken Sie im Workspace-Menü auf **Suche**. Eine Liste aller verfügbaren Inhalte (FAQs, Ankündigungen und Artikel) wird angezeigt.
  2. Klicken Sie in der Liste auf ein Element, um ausführlichere Informationen anzuzeigen.

  Um nach einem bestimmten Inhalt zu suchen, geben Sie einen geeigneten Text in das Feld **Suche nach** ein (oben links auf der Seite) und klicken Sie auf das Symbol :inlineImage[]{src="https://api.qa.archbee.co/api/optimize/yzXkkCTORWlcwRG_AVHKZ/2O5lsWpqLUOCsANln6FA-_search-icon14x13.png" alt caption}.

  Klicken Sie zum Filtern der Liste im linken Bereich auf ein Element (FAQ, Ankündigung oder Wissensartikel) oder auf einen Zeitraum (erstellt in den letzten 7 Tagen, 30 Tagen usw.)
</ExpandableHeading>
