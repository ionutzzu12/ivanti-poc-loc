Die Begrüßungsseite des Enterprise Self Service ist eine Art Zentrale, in der sich der gesamte Self-Service-Inhalt nach Abteilung unterteilt befindet. Von dort aus können Sie zum Self Service Mobile-Portal wechseln, indem Sie die gewünschte Abteilung auswählen, zum Beispiel IT-Services, Personalwesen, Facility Management oder Security Operations.

Wenn Sie beispielsweise auf der Enterprise-Begrüßungsseite **Personalwesen** auswählen, werden Sie zum Self Service Mobile-Portal weitergeleitet, jedoch bezieht sich der dort angezeigte Inhalt (**Servicekataloge**, **Ankündigungen**, **FAQs**, **Meine Elemente** und **Wissensartikel**) nur auf das Personalwesen. Wenn Sie **Security Operations** wählen, wird nur Inhalt für den Bereich Security Operations angezeigt.

Diese Funktion ist nur verfügbar, wenn sie von Ihrem Administrator aktiviert wurde. Wenden Sie sich bei Bedenken oder Fragen an den Administrator Ihrer Organisation.

Beachten Sie bei der Gestaltung der Enterprise-Begrüßungsseite die folgenden Empfehlungen für Bild-/Logoformat, Größe und Auflösung:

| Element         | Format     | Größenlimit | Auflösung                  |
| --------------- | ---------- | ----------- | -------------------------- |
| Logo            | .svg       | 1 MB        | -                          |
| Hintergrundbild | .jpg, .png | 2 MB        | 1920 (Breite) x 550 (Höhe) |
| Kartenlogo      | .svg       | 1 MB        | -                          |
