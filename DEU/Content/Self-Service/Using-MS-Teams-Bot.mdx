Mithilfe des \{\{FRS\_VARS.Company}} Service Manager Bots können Sie verschiedene Aktionen durchführen, etwa einen Incident einreichen, den Status eines Incidents prüfen oder mit einem Analysten chatten.

1. Öffnen Sie den \{\{FRS\_VARS.Company}} Service Manager Bot und senden Sie eine Nachricht.

<hint type="info">
  Falls der Bot nicht zur Verfügung steht, bitten Sie den Administrator Ihrer Organisation, ihn zu konfigurieren.
</hint>

2. Wählen Sie nach Bedarf aus den folgenden Optionen.
   - **Ticket erstellen** – Hierüber erstellen Sie einen Incident.
   - **Status meines Tickets prüfen** – Der Status aller offenen Incidents wird angezeigt.
   - **Mit Support chatten** – Sie werden mit einem Analysten verbunden, der Ihnen bei der Lösung Ihres Problems/bei Ihrer Anfrage behilflich ist.
     - Falls Ihr Chat nicht von einem Analysten angenommen wird, erhalten Sie folgende Meldung: "Bitte bleiben Sie dran. Wir versuchen, einen Analysten für Sie zu finden". Sie können warten, bis Sie verbunden werden.
     - Wenn keiner der Analysten online ist, wird folgende Meldung eingeblendet: "Alle Analysten sind offline". Sie können warten, bis ein Analyst online geht oder den Chat beenden. Die maximale Wartezeit für die Verbindung mit einem Analysten beträgt 5 Minuten. Danach wird folgende Meldung angezeigt: "Wir können momentan leider keine Verbindung herstellen." Klicken Sie auf **Ja**, um den Bot weiterhin zu verwenden, oder auf **Nein**, um den Bot zu beenden.
   - **Chat beenden**: Der Chat wird beendet.
   - **Hilfe** – Zeigt ein Dialogfeld an, in dem die obigen Optionen beschrieben sind.

<hint type="info">
  - Wenn Sie eine Textnachricht senden, statt eine der angebotenen Optionen zu wählen, wird folgende Meldung angezeigt: "Auswahl ungültig. Bitte wählen Sie eine der verfügbaren Optionen aus."
  - Immer dann, wenn der Bot Optionen anzeigt, muss aus diesen Optionen gewählt werden. Andernfalls wird eine Meldung angezeigt, die darauf hinweist, dass nur die angezeigten Optionen zulässig sind.
</hint>
