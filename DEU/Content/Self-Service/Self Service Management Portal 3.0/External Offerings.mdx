Sie greifen über externe Angebote auf \{\{FRS\_VARS.Request\_Offering-Request-Angebot}} zu und übermitteln sie, indem Sie auf eine URL auf einer externen Website klicken. Sie können Services anzeigen und anfordern, Anfragen mithilfe von Benutzer- und Angebots-IDs in der URL verfolgen und wählen, wie die Anfrage angezeigt wird – entweder in einem neuen Fenster, innerhalb von \{\{FRS\_VARS.ProductName-Service-Manager}} oder im **Servicekatalog**.

Führen Sie folgende Schritte aus, um die von Ihrem Administrator erstellten externen Angebote zu nutzen:

1. Melden Sie sich bei \{\{FRS\_VARS.ProductName-Service-Manager}} an.
2. Machen Sie im Workspace **Servicekatalog** über die Suchleiste den Datensatz für das externe Angebot ausfindig.

<Paragraph indent="1">
  Die Datensätze zu externen Angeboten werden angezeigt.
</Paragraph>

3. Klicken Sie auf eine Karte für ein externes Angebot.

<Paragraph indent="1">
  In einem Dialogfeld werden Sie aufgefordert, fortzufahren oder auf der Seite zu bleiben.
</Paragraph>

4. Bei Auswahl von **Fortfahren** wird die URL zusammen mit Ihrer Benutzer-ID und der Angebots-ID in einer neuen Registerkarte geöffnet.
