Die Chat-Zone ist eine Instant Messaging-Funktion, die zum Workspace **Social Board** gehört. Über die Chat-Zone können Sie direkt mit anderen Anwendern kommunizieren. Die Chat-Zone wird nur angezeigt, wenn Ihr Administrator diese für Ihre Anwenderrolle aktiviert hat.

Dies sind die Funktionen der Chat-Zone:

- Falls aktiviert, wird die Chat-Zone automatisch rechts im Workspace "Social Board" angezeigt. An Sie gesendete Chats werden erst angezeigt, wenn Sie den Workspace **Social Board** oder die Chat-Zone öffnen.
- Sie können bis zu zehn verschiedene Konversationen gleichzeitig im Chat aktiv haben.
- Nachdem Sie den Workspace **Social Board** geöffnet haben (wodurch die Chat-Zone aktiviert wird), können Sie den Workspace wieder schließen und weiterhin Chats senden und empfangen. Schalten Sie zum Ausblenden/Einblenden der Chat-Zone den Schalter in der Seitenleiste um.

<ExpandableHeading>
  ## So chatten Sie mit anderen Anwendern:

  1. Klicken Sie im Workspace-Menü auf **Social Board**. Falls die Funktion aktiviert ist, wird die Chat-Zone automatisch im rechten Seitenbereich angezeigt. Falls nicht, wenden Sie sich an Ihren Administrator.
  2. Klicken Sie zum Starten eines Chats in der Chat-Zone auf **Neues Gespräch beginnen**. Ein Chatfenster wird angezeigt.
  3. Gehen Sie folgendermaßen vor, um Anwender hinzuzufügen:
     - Klicken Sie auf **Person hinzufügen**.
     - Geben Sie in das eingeblendete Textfeld den Namen der Person ein, mit der Sie chatten möchten.
     - Klicken Sie auf **Hinzufügen**. Wiederholen Sie den Vorgang, so oft wie nötig. Die Anzahl der aufzunehmenden Personen ist unbegrenzt.
  4. Geben Sie im unteren Bereich eine Nachricht ein.
  5. Drücken Sie die EINGABETASTE, um die Nachricht zu veröffentlichen. Andere Anwender können Ihre Nachricht erst sehen, nachdem Sie sie veröffentlicht haben. Ihre Nachricht wird unter der Empfängerliste angezeigt:
     - **Öffentliche** Gespräche haben einen weißen Hintergrund.
     - **Private** Gespräche haben einen blauen Hintergrund.
  6. Um das Gespräch zu minimieren, klicken Sie in den Gesprächskopf. Klicken Sie erneut in den Gesprächskopf, um das Gespräch wieder zu öffnen.
  7. Klicken Sie zum Entfernen eines Gesprächs auf das Symbol für **Gespräch aus Chat-Zone entfernen** :inlineImage[]{src="https://api.qa.archbee.co/api/optimize/yzXkkCTORWlcwRG_AVHKZ/7wVDR_aHpFr3D7Jas3p7o_chat-remove-icon17x14.png" alt caption}.
</ExpandableHeading>

<ExpandableHeading>
  ## So chatten Sie mit einem Team, einer Gruppe oder einer Rolle:

  In der Chat-Zone (sowie im Social Board) können Sie auf Team-, Gruppen- oder Rollenebene Gespräche führen. Sie können nur mit Teams, Gruppen und Rollen chatten, denen Sie selbst angehören. Vor dem Starten des Chats müssen Sie das Gespräch im Social Board initiieren.

  1. Klicken Sie im Workspace-Menü auf **Social Board**.
  2. Geben Sie eine Nachricht in das Textfeld ein.
  3. Klicken Sie auf **Gruppe hinzufügen**.
  4. Wählen Sie ein Team, eine Gruppe oder eine Rolle aus der Dropdownliste aus und klicken Sie anschließend auf **Hinzufügen**.
  5. Klicken Sie auf **Mitteilen**. Die Nachricht wird im Social Board angezeigt und das Gespräch wird an das Team übermittelt.
  6. Klicken Sie im Meldungsfenster auf das Chatsymbol :inlineImage[]{src="https://api.qa.archbee.co/api/optimize/yzXkkCTORWlcwRG_AVHKZ/RhRJdLssHf6KG_kVWQT3G_chat-icon17x15.png" alt caption}, um das Gespräch in die Chat-Zone zu verschieben. Sie können weiterhin über die Chat-Zone mit der Gruppe chatten.
</ExpandableHeading>

<ExpandableHeading>
  ## So verschieben Sie das Chatfenster:

  Nach dem Veröffentlichen eines Gesprächs können Sie das Chatfenster über anderen Fenstern anordnen, um das Gespräch weiterhin zu verfolgen.

  1. Klicken Sie im Gesprächskopf auf das Pfeilsymbol :inlineImage[]{src="https://api.qa.archbee.co/api/optimize/yzXkkCTORWlcwRG_AVHKZ/efgr7haxz0wR5wcLFh6wE_chat-arrow-icon15x15.png" alt caption}.
  2. Um das Chatfenster zu verschieben, ziehen Sie den Kopf an eine andere Stelle.
  3. Um das Fenster wieder in die Chat-Zone zu verschieben, ziehen Sie es dorthin zurück. Wenn Sie auf das Symbol zum Schließen klicken, wird das Gespräch aus der Chat-Zone entfernt.
</ExpandableHeading>
