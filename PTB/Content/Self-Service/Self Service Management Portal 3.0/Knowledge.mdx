<hint type="info">
  O módulo \{\{FRS\_VARS.Knowledge-Conhecimento}} não está disponível por padrão. Esse espaço de trabalho aparece somente se o administrador o tiver configurado para a sua função.
</hint>

O espaço de trabalho \{\{FRS\_VARS.Knowledge-Conhecimento}} lhe permite acessar todos os artigos disponíveis no Centro de Conhecimento para encontrar soluções ou alternativas para os seus problemas. Ele exibe os artigos mais úteis e recentes para ajudar você a solucionar suas dúvidas.

<ExpandableHeading>
  ## Visualizar artigos de conhecimento

  1. Faça login no Neurons for ITSM.
  2. No menu à esquerda, selecione \{\{FRS\_VARS.Knowledge-Conhecimento}}.

  A lista de \{\{FRS\_VARS.Knowledge-Conhecimento}} artigos é exibida.

  3. Clique em um artigo para visualizar o conteúdo.

  Para procurar um artigo de conhecimento específico, digite uma palavra-chave no campo **Pesquisar** (canto superior direito da página) e pressione **Enter**. Os resultados correspondentes são mostrados.
</ExpandableHeading>

<ExpandableHeading>
  ## Pesquisar artigos de conhecimento

  1. No espaço de trabalho \{\{FRS\_VARS.Knowledge-Conhecimento}}, insira uma palavra-chave no campo **Pesquisar**.
  2. Pressione **Enter**.

  A lista de \{\{FRS\_VARS.Knowledge-Conhecimento}} artigos é exibida.
</ExpandableHeading>

<ExpandableHeading>
  ## Filtrar e classificar artigos

  No espaço de trabalho \{\{FRS\_VARS.Knowledge-Conhecimento}}, você pode usar **Filtrar e Classificar** para restringir ou organizar a lista de artigos.

  Para filtrar artigos

  1. Clique na lista suspensa **Filtrar e Classificar** e expanda **Filtrar por**
  2. Escolha entre as seguintes opções de filtro:
     - **Autor** - Meu
     - **&#x20;Atribuição** - Não atribuído, Minha equipe, Meu
     - **Status** - Pendente, Publicado, Aprovação pendente, Em revisão, Arquivado, etc.
     - **Data de publicação** - Hoje, Esta semana, Este mês, Este ano
     - **Data de vigência** - Hoje, Esta semana, Este mês, Este ano
     - **Mais opções** - Vinculado a um - \{\{FRS\_VARS.Incident-Incidente}}; ou Problema; ou IC
     - **Categoria** - Acessibilidade, Backup, Desktop - Hardware, Software, Telefone, etc.
     - **Classificação do usuário** - com base no número de estrelas
     - **Criado em** - dos últimos 7 dias até 1 ano
     - \{\{FRS\_VARS.Knowledge-Conhecimento}} **tipo** - Documento, Mensagem de erro, FAQ, Patch, Q\&A, Referência

  Para classificar artigos

  1. Expandir **Classificar por**
  2. Escolha uma ordem de classificação: **Crescente** ou **Decrescente**
  3. Selecione um campo de classificação:
     - **Título**
     - **Descrição**
     - **Data de publicação**
     - **Palavras-chave**
  4. Clique em **Aplicar** para atualizar os artigos.
</ExpandableHeading>

<ExpandableHeading>
  ## Usar favoritos para salvar e exibir artigos de conhecimento

  <hint type="info">
    Esse recurso fica disponível apenas se o seu administrador o tiver habilitado para a sua função.
  </hint>

  Você pode marcar artigos de conhecimento importantes como favoritos para acessá-los facilmente mais tarde a partir de uma exibição filtrada.

  **Marcar um artigo como favorito**

  No espaço de trabalho \{\{FRS\_VARS.Knowledge-Conhecimento}}, clique no ícone **Favorito** :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/GyxYlVW5eUjTB8tqsagra_favorites-disabled15x12.png" alt caption} ao lado do artigo que deseja salvar.

  - O ícone muda para :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/F3SoWdp86RQ8ZtlFn98_j_favorites-selected.png" alt caption} para indicar que o artigo agora está nos favoritos.
  - Uma mensagem de confirmação é exibida e o artigo é movido para o topo da lista com seus outros favoritos.

  **Exibir seu artigo favorito**

  No espaço de trabalho \{\{FRS\_VARS.Knowledge-Conhecimento}}, em **Pesquisas Favoritas**, selecione **Meus Conhecimentos Favoritos** na lista suspensa.

  - Os artigos salvos aparecem segundo a forma como o administrador configurou a exibição de favoritos: **Artigos Urgentes**, **Políticas de RH** ou **Todos os Artigos de Conhecimento Publicados**.
</ExpandableHeading>

<ExpandableHeading>
  ## Fornecer feedback a um artigo

  1. No espaço de trabalho \{\{FRS\_VARS.Knowledge-Conhecimento}}, selecione o artigo que deseja avaliar.

  <Paragraph indent="1">
    O artigo de \{\{FRS\_VARS.Knowledge-Conhecimento}} selecionado é exibido.
  </Paragraph>

  2. Clique em **Sim** ou **Não** abaixo de **Este artigo foi útil**?
  3. Em **Avaliar este artigo**, selecione uma classificação por estrelas:
     - 1 estrela = Não é útil
     - 5 estrelas = Exatamente o que eu estava procurando
  4. (Opcional) Insira feedback detalhado na **seção** Feedback.
  5. Clique em **Enviar feedback**.
  6. Para atualizar seu feedback posteriormente, clique no ícone , faça as alterações e clique em **Atualizar feedback**.
</ExpandableHeading>
