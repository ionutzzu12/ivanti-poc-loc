Você pode usar o bot de gerenciamento de serviços \{\{FRS\_VARS.Company}} para executar várias ações, como criar um incidente, verificar o status do incidente e conversar com um analista.

1. Abra o bot de gerenciamento de serviços \{\{FRS\_VARS.Company}} e envie uma mensagem.

<hint type="info">
  Se o bot não estiver disponível para você, entre em contato com o administrador da sua organização para configurá-lo.
</hint>

2. Selecione qualquer uma das opções a seguir, conforme necessário.
   - **Criar um ticket** — cria um incidente.
   - **Verificar o status do meu ticket** — o status de todos os incidentes abertos é exibido.
   - **Chat com suporte** — você será conectado a um analista para ajudar você com seu problema/consulta.
     - Se um analista não atender seu bate-papo, você receberá uma mensagem dizendo "Aguarde, enquanto conectamos você a outro analista". Você pode esperar para ser conectado.
     - Se nenhum analista estiver on-line, você receberá a mensagem - "Todos os analistas estão offline". Você pode continuar esperando até que um analista esteja on-line ou sair. O tempo máximo de espera para conectar você a um analista é de 5 minutos, após os quais a seguinte mensagem é exibida - "Desculpe, não podemos conectar você neste momento." Clique em **Sim** para continuar usando o bot ou **Não** para sair.
   - **Sair da conversa no chat** - sai do chat.
   - **Ajuda** — exibe uma caixa de diálogo que descreve as opções acima.

<hint type="info">
  - Se você enviar uma mensagem de texto em vez de selecionar uma das opções fornecidas, a seguinte mensagem será exibida — "Seleção inválida. Selecione uma das opções disponíveis."
  - Sempre que o bot exibir opções, certifique-se de selecionar uma das opções fornecidas. Caso contrário, uma mensagem inválida será exibida solicitando que você selecione apenas uma das opções exibidas.
</hint>
