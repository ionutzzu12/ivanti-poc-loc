企业自助服务欢迎页面是一个内容中心，根据部门组织所有自助服务内容。 从此处，您可以通过选择要访问的部门（例如 IT 服务、人力资源、设施服务或安全运营）导航至相应的自助服务移动版门户。

例如，如果您在企业欢迎页面上选择**人力资源**，您将重定向至自助服务移动版门户，但其中显示的内容（**服务目录**、**公告**、**常见问题解答**、**我的项目**和**知识文章**）将特定于人力资源。 同样，如果您选择**安全运营**，将显示安全运营的内容。

仅当您的组织的管理员为您启用此功能后，您才可使用此功能。 如果您有任何顾虑或疑问，请联系您的组织的管理员。

设计企业欢迎页面时，请遵循以下图像/徽标格式、大小和分辨率建议：

| 元素   | 格式        | 大小限制 | 分辨率             |
| ---- | --------- | ---- | --------------- |
| 徽标   | .svg      | 1 MB | -               |
| 背景图像 | .jpg、.png | 2 MB | 1920（宽）x 550（高） |
| 卡片徽标 | .svg      | 1 MB | -               |
