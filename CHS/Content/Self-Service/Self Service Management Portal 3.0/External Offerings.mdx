您可以通过点击外部网站上的 URL 并通过外部提供来访问和提交 \{\{FRS\_VARS.Request\_Offering-tlb-alardh..}}。 您查看和请求服务，使用 URL 中的用户和产品 ID 跟踪您的请求，并选择请求的显示方式 - 在新窗口中、在 \{\{FRS\_VARS.ProductName}} 中或在**服务目录**中。

要使用管理员创建的外部服务，请按照以下步骤操作：

1. 登录 \{\{FRS\_VARS.ProductName}}。
2. 在**服务目录**工作区中，搜索外部服务记录。

<Paragraph indent="1">
  随即显示外部服务记录。
</Paragraph>

3. 点击外部服务卡。

<Paragraph indent="1">
  随即出现对话框，提示您确定是要继续，还是留在当前页面。
</Paragraph>

4. 如果您选择**继续**，URL 会在新选项卡中打开，其中包含您的用户 ID 和服务 ID。
