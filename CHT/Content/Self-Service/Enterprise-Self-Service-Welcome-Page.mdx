企業自助服務歡迎使用頁面是一個中樞頁面，其中提供基於部門所組織的所有自助服務內容。 在此，您只需選取想要存取的部門 (如 IT 服務、人力資源、設施服務或安全性作業等) 即可瀏覽相應的自助服務行動版入口網站。

例如，假設您選取了企業歡迎使用頁面上的**人力資源**，系統會將您重新導向至自助服務行動版入口網站，但其中顯示的內容 (**服務目錄**、**公告**、**常見問題集**、**我的項目**，以及**知識文章**等) 將僅特定於人力資源範圍。 同樣地，若您選取的是**安全性作業**，有關安全性作業的內容隨即顯示。

僅當貴組織的管理員為您啟用此功能時，您才能使用此功能。 如您有任何疑慮或疑問，請與貴組織的管理員聯絡。

設計企業歡迎頁面時，請按照以下圖片/標誌格式、大小和解析度建議:

| 項目   | 格式        | 大小限制 | 解析度                |
| ---- | --------- | ---- | ------------------ |
| 標誌   | .svg      | 1 MB | -                  |
| 背景圖片 | .jpg、.png | 2 MB | 1920 (寬) x 550 (高) |
| 卡片標誌 | .svg      | 1 MB | -                  |
