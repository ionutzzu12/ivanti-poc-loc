バージョン: 2022.4

\{\{FRS\_VARS.Company}} \{\{FRS\_VARS.Neurons\_for\_Facilities}} 2022.4は、セルフサービス ユーザ向けに、既存の \{\{FRS\_VARS.ProductName-Service-Manager.}} システムのための拡張施設機能を提供します。

セルフサービス ユーザは、\{\{FRS\_VARS.Neurons\_for\_Facilities}} 2022.4を使用して \{\{FRS\_VARS.Company-short}} \{\{FRS\_VARS.ProductName-Service-Manager.}} にログオンすると、次のことを行えます。

- 利用可能な会議室、施設スペース、仕事スペースの予約。
- 自分に割り当てられている、別の施設に移動する際に持ち込みたい、さまざまな施設資産の選択。
- 「施設資産申請」機能が改善され、ユーザ エクスペリエンスと使い勝手が向上しています。

上述の拡張機能はすべて、サービス カタログの「施設サービス」セクションで利用できます。

サービス申請を行うための一般的な手順については、「[サービス申請とインシデント](service-requests-and-incidents.mdx)」をご参照ください。

サービス カタログで選択できるすべての申請機能については、「[既定のサービス カタログ項目](<https://help.ivanti.com/ht/help/en_US/ISM/2026/admin-user/Content/ServiceDesk/ServiceCatalog/Default Catalog Offerings.htm>)」をご参照ください。

\{\{FRS\_VARS.Company-short}} \{\{FRS\_VARS.Neurons\_for\_Facilities}} 2022.4で新たに提供される、または改善された申請機能を以下に示します。

## 従業員の移動申請

申請者に割り当てられている資産も含めた、ある施設から別の施設への移動申請。

**従業員の移動申請を作成するには:**

1. セルフサービス ポータルの **\[ホーム]** ワークスペースで、**\[すべてのサービス]** を選択します。
2. **\[施設サービス]** カテゴリを選択した後、**\[従業員の移動申請]** を選択します。
3. 申請の完了についての詳細は、「既定のサービス カタログ項目」の「[従業員の移動申請](<https://help.ivanti.com/ht/help/en_US/ISM/2026/admin-user/Content/ServiceDesk/ServiceCatalog/Default Catalog Offerings.htm>)」をご参照ください。
4. すべてのフィールドに入力した後、**\[送信]** をクリックします。

## 施設予約

ケータリングや必要な備品も含め、会議室、仕事スペース、施設スペースを予約します。

**予約するには:**

1. セルフサービス ポータルの **\[ホーム]** ワークスペースで、**\[すべてのサービス]** を選択します。
2. **\[施設サービス]** カテゴリを選択した後、**\[施設予約]** を選択します。
3. 申請の完了についての詳細は、「既定のサービス カタログ項目」の「[施設予約申請](<https://help.ivanti.com/ht/help/en_US/ISM/2026/admin-user/Content/ServiceDesk/ServiceCatalog/Default Catalog Offerings.htm>)」をご参照ください。
4. すべてのフィールドに入力した後、**\[送信]** をクリックします。

## 施設資産申請

製品カタログから新しい施設資産を申請します。

**施設資産を申請するには:**

1. セルフサービス ポータルの **\[ホーム]** ワークスペースで、**\[すべてのサービス]** を選択します。
2. **\[施設サービス]** カテゴリを選択した後、**\[施設資産申請]** を選択します。
3. 申請の完了についての詳細は、「既定のサービス カタログ項目」の「[施設資産申請](<https://help.ivanti.com/ht/help/en_US/ISM/2026/admin-user/Content/ServiceDesk/ServiceCatalog/Default Catalog Offerings.htm>)」をご参照ください。
4. すべてのフィールドに入力した後、**\[送信]** をクリックします。
