外部 Web サイト上の URL をクリックすることで、外部サービス項目を介して \{\{FRS\_VARS.Request\_Offering-tlb-alardh...}} にアクセスして送信します。 サービスを表示して申請し、URL でユーザ ID とサービス項目 ID を使用して申請を追跡し、申請をどのように表示するか (新しいウィンドウに表示するか、\{\{FRS\_VARS.ProductName-Service-Manager.}} 内に表示するか、**サービス カタログ**内に表示するか) を選択します。

管理者が作成した外部サービス項目を使用するには、次の手順に従います。

1. \{\{FRS\_VARS.ProductName-Service-Manager.}} にログインします。
2. **\[サービス カタログ]** ワークスペースで、検索バーを使用して外部サービス項目レコードを検索します。

<Paragraph indent="1">
  外部サービス項目のレコードが表示されます。
</Paragraph>

3. 外部サービス項目のカードをクリックします。

<Paragraph indent="1">
  続行、またはページにとどまるよう促すダイアログが表示されます。
</Paragraph>

4. **\[続行]** を選択すると、ユーザ ID とサービス項目 ID が含まれた別のタブに URL が開きます。
