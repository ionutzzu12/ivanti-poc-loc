エンタープライズ セルフサービス ようこそページは、すべての セルフサービス コンテンツが部署別に整理されているハブです。 ここから、IT サービス、人事、施設サービス、セキュリティ オペレーションなど、アクセスしたい部署を選択することで、セルフサービス モバイル ポータルに移動できます。

たとえば、エンタープライズ ようこそページで **\[人事]** を選択した場合、セルフサービス モバイル ポータルにリダイレクトされますが、そこに表示されるコンテンツ (**\[サービス カタログ]**、**\[お知らせ]**、**\[FAQ]**、**\[マイ項目]**、 **\[ナレッジ記事]**) は、人事固有のコンテンツです。 同様に、**\[セキュリティ オペレーション]** を選択した場合は、キュリティ オペレーションのコンテンツが表示されます。

この機能は、組織の管理者が有効にしている場合にのみ使用できます。 問題やご質問がある場合は、組織の管理者にお問い合わせください。

エンタープライズ ようこそページを設計する際は、画像/ロゴの形式、サイズ、解像度に関する以下の推奨事項に従ってください。

| 要素     | 形式         | サイズ制限 | 解像度                 |
| ------ | ---------- | ----- | ------------------- |
| ロゴ     | .svg       | 1 MB  | -                   |
| 背景の画像  | .jpg, .png | 2 MB  | 1920 (幅) x 550 (高さ) |
| カード ロゴ | .svg       | 1MB   | -                   |
