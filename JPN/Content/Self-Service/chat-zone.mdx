チャットゾーンは、インスタント メッセージング機能であり、**\[ソーシャル ボード]** ワークスペースの一部です。 チャット ゾーンを使用して、他のユーザと直接対話します。 ご自分のユーザ ロールに対して管理者がチャット ゾーンを有効にしてある場合のみ、チャット ゾーンが表示されます。

チャット ゾーンには、次の特徴があります。

- 有効になっていれば、\[ソーシャル ボード] ワークスペースの右側にチャット ゾーンが自動的に表示されます。 自分宛に送信されたチャットは、**\[ソーシャル ボード]** ワークスペースまたはチャット ゾーンを開かない限り表示されません。
- チャットで一度にアクティブにできる会話の数は、最大10件までです。
- **\[ソーシャル ボード]** ワークスペースを開いた後は (チャット ゾーンがアクティブになります)、同ワークスペースを閉じても、引き続きチャットの送受信を行えます。 チャットゾーンを非表示にする/表示するには、 サイドバー ハンドルで切り替えます。

<ExpandableHeading>
  ## 他のユーザとチャットするには

  1. ワークスペース メニューで **\[ソーシャル ボード]** をクリックします。 チャット ゾーンは、有効になっていればページの右側に自動的に表示されます。表示されない場合は、管理者にお問い合わせください。
  2. チャットを始めるには、チャット ゾーン内で **\[新規会話を開始]** をクリックします。 チャット ウィンドウが表示されます。
  3. ユーザを追加するには、以下の手順を行います。
     - **\[ユーザを追加]** をクリックします。
     - 表示されたテキスト ボックスに、チャットの相手となるユーザの名前を入力します。
     - **\[追加]** をクリックします。 必要に応じて手順を繰り返します。含めるユーザの数に制限はありません。
  4. 最下部のメッセージ領域に、メッセージを入力します。
  5. ENTER キーを押してメッセージを公開します。 公開するまで、メッセージは相手ユーザに表示されません。 送信したメッセージは、宛先リストの下に表示されます。
     - **パブリック**の会話は、背景が白になります。
     - **プライベート**の会話は、背景が青になります。
  6. 会話を最小化するには、会話のヘッダーをクリックします。 最小化した会話を開くには、もう一度ヘッダーをクリックします。
  7. 会話を削除するには、**\[チャットゾーンの会話を削除]**:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/X-A8fN5Bhxle56vdZ9ZNW_chat-remove-icon17x14.png" alt caption} アイコンをクリックします。
</ExpandableHeading>

<ExpandableHeading>
  ## チーム、グループ、またはロールとチャットするには

  チャットゾーン (およびソーシャル ボード) では、チーム、グループ、またはロールのレベルで会話を行えます。 自分が属するチーム、グループ、またはロールのみとチャットを行えます。 チャットを開始する前に、まずソーシャル ボードで会話を開始する必要があります。

  1. ワークスペース メニューで **\[ソーシャル ボード]** をクリックします。
  2. テキスト ボックスにメッセージを入力します。
  3. **\[グループを追加]** をクリックします。
  4. チーム、グループ、またはロールをドロップダウン リストから選択し、**\[追加]** をクリックします。
  5. **\[共有]** をクリックします。 メッセージがソーシャル ボードに表示され、会話がチームに送信されます。
  6. メッセージ ウィンドウでチャット :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/N4lbCf8QNqsCC5YNEE88W_chat-icon17x15.png" alt caption} アイコンをクリックして、会話をチャット ゾーンに移動します。 チャット ゾーンで、グループとのチャットを続行できます。
</ExpandableHeading>

<ExpandableHeading>
  ## チャット ウィンドウを移動するには

  会話を公開した後、チャット ウィンドウを他のウィンドウの上に配置して、引き続き会話を監視できます。

  1. 会話のヘッダー内にある、ポップアウト矢印:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/A4ixw5-EVRKk-9O19slSg_chat-arrow-icon15x15.png" alt caption}アイコンをクリックします。
  2. チャット ウィンドウを移動するには、ヘッダーを別の場所までドラッグします。
  3. ウィンドウをチャット ゾーンに戻すには、ドラッグ アンド ドロップでチャット ゾーンに戻します。 クローズ アイコンをクリックすると、会話がチャット ゾーンから削除されます。
</ExpandableHeading>
