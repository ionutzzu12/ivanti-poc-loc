## Configuring a SQL Server Always On High Availability Group

ITSM supports the **SQL Server Always On High Availability Group** feature. To configure, refer the [Microsoft documentation](https://learn.microsoft.com/en-us/azure/azure-sql/virtual-machines/windows/availability-group-manually-configure-tutorial-single-subnet?view=azuresql).

| Database Management Software | \{\{Primary.Product}} Release 2026 |
| ---------------------------- | ---------------------------------- |
| Microsoft SQL Server 2017 \* | C                                  |
| Microsoft SQL Server 2019    | C                                  |
| Microsoft SQL Server 2022    | C                                  |
| Microsoft SQL Server 2025    | C                                  |

\* ITSM 2026.1 is the last version to support SQL Server 2017.

<hint type="info">
  - After configuring the **SQL Server Always On High Availability Group**, make sure to rerun the System Configuration Wizard by providing availability group listener name in the **Configuration Database Server Name** section.
  - The Ops Console doesn’t work when the **SQL Server Always On High Availability Group** is enabled.
  - When upgrading, make sure to remove the databases from the availability group. Once the upgrade is complete, you can add the databases back to the availability group.
</hint>
