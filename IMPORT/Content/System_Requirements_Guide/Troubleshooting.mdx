If you have problems with your installation or deployment, check this section first.

## 1

**Problem**: The \{\{Primary.Product}} web servers do not work correctly.

**Possible Cause**: In multi-server environments, each \{\{Primary.Product}} web server must meet the system requirements.

**Solution**: See "Web Server Requirements".

## 2

**Problem**: I am unable to use integrated components, such as \{\{Primary.Product}} Voice.

**Possible Cause**: You must use the Microsoft Windows operating system when you use integrated components.

**Solution**: Change to the Microsoft Windows operating system. See "Client Computer Requirements".

## 3

**Problem**: I am using Google Chrome and cannot download or edit reports.

**Possible Cause**: You have not installed the ClickOnce extension yet.

**Solution**: Install the ClickOnce extension for Google Chrome. Navigate to [https://chrome.google.com/webstore/detail/meta4-clickonce- launcher/jkncabbipkgbconhaajbapbhokpbgkdc?hl=en](<https://chrome.google.com/webstore/detail/meta4-clickonce- launcher/jkncabbipkgbconhaajbapbhokpbgkdc?hl=en>) to download the extension. See "Client Computer Requirements".
