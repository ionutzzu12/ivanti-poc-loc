- A top-level tab area that you use to select the workspace to display. Click any tab to open it in the workspace display area. When you select a tab, the system displays the tab name in a pink font.

### About the Tenants Workspace

Use the Tenants workspace to perform a variety of tenant management activities, including creating, locking, migrating, and deleting tenants and tenant instances. See :Link[Working with Tenants and Tenant Instances]{label="Working with Tenants and Tenant Instances" overridedLabel="Working with Tenants and Tenant Instances" spaceId docId="E1As7bRqncH4Ipv9Eksy7" version="v2" docAnchorId="#Working" loadingMethod="dynamic" newTab="false" githubPath="OpsConsole_Tenants.htm#Working" href="OpsConsole_Tenants.mdx"}.

### About the Users Workspace

Use the Users workspace to view and edit information about the users who can access the Operations Console. See :Link[Working With Operations Console Users]{label="Working With Operations Console Users" overridedLabel="Working With Operations Console Users" spaceId docId="hWnDisjDllHtpIXJH33qw" version="v2" docAnchorId="#About" loadingMethod="dynamic" newTab="false" githubPath="OpsConsole_Using.htm#About" href="OpsConsole_Using.mdx"}.

### About the System Status Workspace

Use the System Status workspace to view status information about the entire Ivanti Service Manager system. See :Link[Viewing System Information]{label="Viewing System Information" overridedLabel="Viewing System Information" spaceId docId="hWnDisjDllHtpIXJH33qw" version="v2" docAnchorId="#Use" loadingMethod="dynamic" newTab="false" githubPath="OpsConsole_Using.htm#Use" href="OpsConsole_Using.mdx"}.

### About the Landscape Workspace

Use the Landscape workspace to view and edit information about landscapes. See [Configuring Landscapes](OpsConsole_Landscapes.mdx).

### About the Events & Audit History Workspace

Use the Events & Audit History workspace to view information about each action that has occurred on a tenant or tenant instance. See :Link[Viewing Events and Audit History]{label="Viewing Events and Audit History" overridedLabel="Viewing Events and Audit History" spaceId docId="hWnDisjDllHtpIXJH33qw" version="v2" docAnchorId="#Viewing2" loadingMethod="dynamic" newTab="false" githubPath="OpsConsole_Using.htm#Viewing2" href="OpsConsole_Using.mdx"}.
