### About the Demonstration or Proof-of-Concept Deployment

<hint type="info">
  This deployment is only recommended for demonstration purposes. Do not use this deployment for any production environment.
</hint>

You can run the entire \{\{Primary.Product}} system on a single server for the purpose of a demonstration or a proof-of-concept system.

Install \{\{Primary.Product}}, with all options enabled, onto a single server that has Microsoft SQL Server loaded locally. Most users install this deployment in a virtual environment.

### Hardware Requirements for the Demonstration or Proof-of-Concept Deployment

- 1 server, either virtual or physical
- 1 CPU
- 4 GB memory
- 40 GB hard drive
