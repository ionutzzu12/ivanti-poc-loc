You can also deploy \{\{Primary.Product}} as a virtual image. If you use a virtual machine, always keep the same universally unique identifier (UUID).

Refer to the documentation specific to the virtual machine you are using for more information.

<hint type="info">
  Any virtual machine platform that meets the [System Requirements ](../System_Requirements_Guide/Neurons-for-ITSM-System-Req-Overview.mdx)is compatible with \{\{Primary.Product}}.
</hint>
