## Release Version 2025.3

### Bug ID: 1674149

<table isTableHeaderOn="true">
  <tr>
    <td>
      **Issue**
    </td>
    <td>
      You cannot access the **Service Catalog** business object under the **Service Owner** role if you are not using the **English (United States)** locale. If you have changed your locale to another and try to access any request under **Service Catalog**, you might receive an error stating: Access denied to table Frs\_def\_self\_service\_literals#. This issue is occurred because the Object Permissions are not set properly for the **Frs\_def\_self\_service\_literals** business object.
    </td>
  </tr>
  <tr>
    <td>
      **Expected Result**
    </td>
    <td>
      For any locale, you should be able to access any request under the **Service Catalog** business object.
    </td>
  </tr>
  <tr>
    <td>
      **Actual Result**
    </td>
    <td>
      For non-**English (United States)** locales, you can't access some of the requests under the **Service Catalog** business object.
    </td>
  </tr>
  <tr>
    <td>
      **Workaround**
    </td>
    <td>
      1. Log in to ITSM as an Administrator.
      2. Open the Configuration console, and go to **Configure** > **Users and Permissions** > **Roles and Permissions** > **ServiceOwner** role > **Object Permissions**.
      3. Find **Frs\_def\_self\_service\_literals** business object, and then select the **View** checkbox.
      4. Click **Save**.
    </td>
  </tr>
</table>

### Bug ID: 1369214

<table isTableHeaderOn="true">
  <tr>
    <td>
      **Issue**
    </td>
    <td>
      Inbound web service request fails with null reference object error and the message is stuck in **Dispatched** state.
    </td>
  </tr>
  <tr>
    <td>
      **Workaround**
    </td>
    <td>
      Verify and update the dispatch method name for the type **Web Service Handler** to **HandleWebServiceMessage**.
      5. Login to Config DB of the on-premise environment.
      6. Open the Message Queue Handler Workspace.
      7. Open the handler name **Web Service Handler**.
      8. Update the Dispatch method name to **HandleWebServiceMessage**.
      9. Restart the Ivanti Message Queue Service.

    </td>
  </tr>
</table>
