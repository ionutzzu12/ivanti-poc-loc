## About Ivanti Voice

Ivanti Voice is the telephony application that integrates automated call routing and management and computer telephone integration to Ivanti Software applications such as \{\{Primary.Product}}. Ivanti Voice uses the next-generation, standards‑based IP communication transport, called Session Initiation Protocol (SIP). \{\{Primary.Product}} and Voice are typically installed and maintained on separate servers..

### Agent Login Sequence

:Link[Agent Login Sequence]{label="Agent Login Sequence" overridedLabel="Agent Login Sequence" spaceId docId="T7Nyo4D-i3iKxIkRzIJB5" version="v2" docAnchorId="#Fig_Agent_Login_Sequence" loadingMethod="dynamic" newTab="false" href="Multisrvr_Voice.mdx"} shows the Voice agent login sequence.

*Agent Login Sequence*

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/8lVkNgS1R1v9SnjfkHKYi_voicediagram.png" position="flex-start" size="40" initialPath="Install_Deploy_Images/voice_diagram.png" githubPath="ITSM-On-Prem-Help/Content/Install_Deploy_guide/Install_Deploy_Images/voice_diagram.png"></Image>

1. The agent logs into a secure (HTTPS) connection.
2. The system verifies the Voice server IP address or domain name.
3. The system obtains the session key from the Ivanti Voice server IP address or domain name.
4. The system verifies the session key (TCP 5743).
5. The system makes the phone connection (SIP UDP 5060).
6. The system validates the session key (HTTPS).

### Incoming Call Sequence

:Link[Incoming Call Sequence]{label="Incoming Call Sequence" overridedLabel="Incoming Call Sequence" spaceId docId="T7Nyo4D-i3iKxIkRzIJB5" version="v2" docAnchorId="#Fig_Incoming_Call_Sequence" loadingMethod="dynamic" newTab="false" href="Multisrvr_Voice.mdx"} shows the sequence of events for Ivanti Voice incoming calls.

*Incoming Call Sequence*

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/4l1uPrvY2lstWPLs0G_pM_voicediagramagent.png" position="flex-start" size="40" initialPath="Install_Deploy_Images/voice_diagram_agent.png" githubPath="ITSM-On-Prem-Help/Content/Install_Deploy_guide/Install_Deploy_Images/voice_diagram_agent.png"></Image>

1. The system receives a call (SIP UDP 500).
2. The IVR searches and updates the record (HTTPS).
3. The call is forwarded to the agent (SIP UDP 5060, RTP UDP, TCP 5743).
4. The record appears to the agent (HTTPS).
