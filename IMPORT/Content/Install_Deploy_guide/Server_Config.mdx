As part of the \{\{Primary.Product}} installation, you must configure the system using the System Configuration Wizard. 

The wizard walks you through the first-time set up and configuration as shown in the screen shots below.

1. Click **Install** to begin the installation.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/x7rhbMtOswxQwba4iW7oY_ivantiserviceassetmanager1.png" position="flex-start" size="40" indent="1" initialPath="Install_Deploy_Images/Ivanti_Service_Asset_Manager_1.png" githubPath="ITSM-On-Prem-Help/Content/Install_Deploy_guide/Install_Deploy_Images/Ivanti_Service_Asset_Manager_1.png"></Image>

1. Click **Next**.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/Ni3xIN7VSduMmYGNWsAIZ_ivantiserviceassetmanager2.png" position="flex-start" size="40" indent="1" initialPath="Install_Deploy_Images/Ivanti_Service_Asset_Manager_2.png" githubPath="ITSM-On-Prem-Help/Content/Install_Deploy_guide/Install_Deploy_Images/Ivanti_Service_Asset_Manager_2.png"></Image>

1. Click **Next** to continue the installation process.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/xIQJFRFkbLce1oR3Bk2xM_ivantiserviceassetmanager3.png" position="flex-start" size="40" indent="1" initialPath="Install_Deploy_Images/Ivanti_Service_Asset_Manager_3.png" githubPath="ITSM-On-Prem-Help/Content/Install_Deploy_guide/Install_Deploy_Images/Ivanti_Service_Asset_Manager_3.png"></Image>

1. Select one of the options, **Service Manager**, **Asset Manager**, or **Service and Asset Manager**.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/w1BrYT67JHRAWU-F4zn3P_reportingservices3.png" position="flex-start" size="40" indent="1" initialPath="Install_Deploy_Images/reporting_services_3.png" githubPath="ITSM-On-Prem-Help/Content/Install_Deploy_guide/Install_Deploy_Images/reporting_services_3.png"></Image>

For more information on Asset Manager, see [Ivanti Asset Manager](https://help.ivanti.com/iv/help/en_US/IAMC/2020/Landing-page.htm).

1. Select the **Custom** or **Complete** options.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/F6I6Ffp-hNJXoWR7QqxZ4_ivantiserviceassetmanagersetuptype.png" position="flex-start" size="40" indent="1" initialPath="Install_Deploy_Images/Ivanti_Service_Asset_Manager_Setup_Type.png" githubPath="ITSM-On-Prem-Help/Content/Install_Deploy_guide/Install_Deploy_Images/Ivanti_Service_Asset_Manager_Setup_Type.png"></Image>

1. Click **Next**.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/0sr4ao6zaH0eYUxUvv8a7_ivantiserviceassetmanagerinstallbutton.png" position="flex-start" size="40" indent="1" initialPath="Install_Deploy_Images/Ivanti_Service_Asset_Manager_Install_button.png" githubPath="ITSM-On-Prem-Help/Content/Install_Deploy_guide/Install_Deploy_Images/Ivanti_Service_Asset_Manager_Install_button.png"></Image>

The tabs that you see in the wizard depend on which components that you installed. You may see all of the tabs or you may just see a subset of them.
