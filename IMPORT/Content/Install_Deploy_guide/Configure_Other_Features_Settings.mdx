On this page you will do the following:

- Specify the log file and temporary file locations on the configuration server.
- Specify different servers and ports and whether to use SSL for the other \{\{Primary.Product}} servers.
- Specify the inbound web server information.

<Paragraph indent="1">
  *Other Feature Settings Page*
</Paragraph>

<Paragraph indent="1">
  You can set a list of remote hosts to block and a list of remote hosts to trust. By default, the list is empty.
</Paragraph>

3. To designate a list of blocked servers, do the following:

<Paragraph indent="1">
  a. Next to the Trusted Host & Remote Host Blocked List field, click Set.
</Paragraph>

<Paragraph indent="1">
  b. In the Remote Host Blocked List area, click the plus icon.
</Paragraph>

<Paragraph indent="1">
  c. Enter the starting IP address and the ending IP address for the blocked servers.
</Paragraph>

<Paragraph indent="1">
  d. If you are blocking web scripts, check Is Web Script.
</Paragraph>

<Paragraph indent="1">
  e. Click OK.
</Paragraph>

4. To designate a list of trusted servers, do the following:

<Paragraph indent="1">
  a. Next to the Trusted Host & Remote Host Blocked List field, click Set.
</Paragraph>

<Paragraph indent="1">
  b. In the Integration Trusted Host List area, click the plus icon.
</Paragraph>

<Paragraph indent="1">
  c. Enter a name for the trusted host list.
</Paragraph>

<Paragraph indent="1">
  d. Enter the starting IP address and the ending IP address for the trusted servers.
</Paragraph>

<Paragraph indent="1">
  e. Click OK.
</Paragraph>

<hint type="info">
  To update the list at a later time, run the System Configuration Wizard, advance to the Other Feature Settings page, click Set, and make your changes. When you are done, click OK.
</hint>

5. To restart the \{\{Primary.Product}} services after you exit the System Configuration Wizard, check Restart services after setting configuration files.
6. Verify that the \{\{Primary.Product}} services restart after the wizard closes.
7. If you did not check Restart services after setting configuration files, restart the \{\{Primary.Product}} services manually.
8. Click Next. The system displays the Metrics Server page.
