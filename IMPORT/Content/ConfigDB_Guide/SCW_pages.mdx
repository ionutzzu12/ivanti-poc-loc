The following workspaces found in the ConfigDB contain information that was populated based on information entered in the System Configuration Wizard when \{\{Primary.Product}} was installed.  

We recommend that you do not change any of the values in these workspaces.

For complete information about the System Configuration Wizard and the \{\{Primary.Product}} installation, see the Installation and Deployment Guide for \{\{Primary.Product}} \{\{Primary.Year-2025}}

- Database Servers
- Log Operations Locations
- Integration Services Configuration
- Metrics Server
- Report Server
- Survey Information
- Trusted IP Addresses
- Web Servers
