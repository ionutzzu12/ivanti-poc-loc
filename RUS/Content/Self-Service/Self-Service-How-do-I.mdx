Изучив этот раздел, вы получите информацию, необходимую для выполнения различных задач с использованием рабочих зон. Вы можете отрывать рабочие зоны из меню рабочих зон в строке заголовка в верхней части портала.

<ExpandableHeading>
  ## Показать мои элементы (запросы на обслуживание и инциденты)

  1. В меню рабочей зоны нажмите **Мои элементы**. Отобразится список отправленных вами запросов на обслуживание и созданных инцидентов:
     - Для поиска конкретного элемента введите ключевое слово в поле **Искать в моих элементах** и используйте раскрывающийся список для сужения поиска. Затем нажмите значок :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/pXnbdRKYi07d5CUR6Iyq9_search-icon14x12.png" alt caption}.
     - Нажмите элемент для отображения его информации. Во время просмотра информации вы можете изменить элемент по любой причине, добавив к нему примечание или вложение.

  Для получения дополнительной информации см. раздел [Мои элементы](my-items.mdx).
</ExpandableHeading>

<ExpandableHeading>
  ## Отправка запроса на обслуживание

  1. В меню рабочей зоны нажмите **Каталог услуг**.
  2. Выберите категорию на левой навигационной панели. Для размещения запроса после нахождения правильного элемента выберите его на главной панели.
  3. В появившейся форме введите информацию в поля, если необходимо. Если форма содержит более одной страницы, нажмите **Продолжить** (в правом нижнем углу) для перехода внутри формы. Все формы имеют отличия в зависимости от выбранного типа запроса.
  4. После завершения нажмите **Проверить и отправить** для проверки правильности информации. Для изменения любой информации нажмите **Изменить/Назад** и измените информацию, если необходимо.
  5. Нажмите **Отправить**.

  Вы можете отслеживать этот запрос в вашем списке **Мои открытые элементы** в рабочей зоне **Главная страница** или **Мои элементы**.

  Для получения дополнительной информации см. раздел [Запросы на обслуживание и инциденты](service-requests-and-incidents.mdx).
</ExpandableHeading>

<ExpandableHeading>
  ## Создание инцидента

  1. В меню рабочей зоны нажмите **Каталог услуг**.
  2. На левой навигационной панели нажмите **Сообщить о новом инциденте**. На главной панели выберите вариант, соответствующий вашей проблеме. Если ваша проблема не соответствует доступным вариантам, нажмите **Создать инцидент**.

  <Paragraph indent="1">
    Отобразится форма с автоматически заполненной информацией.
  </Paragraph>

  3. В появившейся форме заполните необходимые поля. Перед тем, как сделать это, откройте слева панель **Возможное решение**, чтобы узнать, можете ли вы решить проблему с помощью одного из предложенных исправлений:
     - Если выбранная статья соответствует вашей проблеме, нажмите ее заголовок, чтобы открыть ее.
     - Если решение подходит, нажмите **Разрешить** (внизу справа на панели) для закрытия инцидента. Если оно не подходит, нажмите **Назад** (внизу слева на панели) для проверки других решений.
  4. Если ни одно из решений не подходит, заполните необходимые поля.
     - В поле **Описание** укажите подробную информацию о вашей проблеме.
     - В поле **Срочность** выберите уровень срочности, который представляет эта проблема.
  5. Нажмите **Сохранить инцидент**.

  После сохранения проблема станет инцидентом с идентификатором, который вы можете отслеживать в вашем списке **Мои открытые элементы** в рабочей зоне **Главная страница** или **Мои элементы**.

  Для получения дополнительной информации см. раздел [Запросы на обслуживание и инциденты](service-requests-and-incidents.mdx).
</ExpandableHeading>

<ExpandableHeading>
  ## Публикация сообщений для команд, групп или пользователей

  1. В меню рабочей зоны нажмите **Форум**.
  2. Нажмите поле **Поделиться новостями** для ввода сообщения. По умолчанию это сообщение отобразится сразу для всех, как только вы поделитесь им. Для сокращения аудитории этого сообщения:
     - Нажмите **Добавить группу**. В раскрывающемся списке выберите команду, группу или роль пользователя для публикации этого сообщения. Нажмите **Добавить**. При необходимости повторите действия.
     - Нажмите **Добавить пользователя**. Начните вводить имя пользователя и выберите одно из списка для отправки этого сообщения. Нажмите **Добавить**. При необходимости повторите действия.
  3. Нажмите **Поделиться** для отправки сообщения. Ваше сообщение отобразится вверху списка.

  Для ответа на сообщение введите информацию в поле **Добавить комментарий** и нажмите клавишу ВВОД.

  Для поиска конкретных сообщений введите текст в поле **Найти публикации** (верхняя левая область страницы) и нажмите значок :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/Ye0KNjP982pZTJUEYI7wa_search-icon14x13.png" alt caption}.

  Для фильтрации списка сообщений на главной панели в реальном времени используйте критерии фильтрации на левой панели "Текущая активность".

  Для получения дополнительной информации см. раздел [Сообщения форума](social-board-messages.mdx).
</ExpandableHeading>

<ExpandableHeading>
  ## Поиск среди всех часто задаваемых вопросов, объявлений или статей знаний

  1. В меню рабочей зоны нажмите **Поиск**. Отобразится список всех доступных данных, среди которых часто задаваемые вопросы, объявления и статьи.
  2. В списке нажмите заголовок для отображения подробной информации.

  Для поиска конкретной информации введите текст в поле **Найти** (верхняя левая область страницы) и нажмите значок :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/Ye0KNjP982pZTJUEYI7wa_search-icon14x13.png" alt caption}.

  Для фильтрации списка выберите тип (часто задаваемый вопрос, объявление или статья знаний) или период времени (создано за последние 7, 30 дней и т.д.) на левой панели.

  Для получения дополнительной информации см. раздел [Объявления, часто задаваемые вопросы и предупреждения](announcements-FAQs-and-alerts.mdx).
</ExpandableHeading>
