Вы можете создавать инциденты или отправлять запросы в портале \{\{FRS\_VARS.Self\_Service\_Mobile\_portal-Mobilnoe-prilozhenie-samoobsluzhivaniya}}. Запрос на обслуживание представляет собой запрос услуги, такой как бронирование помещения для собраний или создание новой учетной записи электронной почты. Проблема же представляет собой прерывание услуг, например, блокировку учетной записи или неисправность принтера.

На некоторых устройствах Каталог услуг можно открыть в виде списка или плиток. Переключайте вид, нажимая значок списка :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/Cc3JJ7ducIrPpi1vlbevm_list-icon16x12.png" alt caption} или значок плитки :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/11XlHZjHcnLKesr5NTlY5_tile-icon16x11.png" alt caption} в правом верхнем углу страницы. Имейте в виду, что вид плиток отображает элементы в виде больших плиток, которые занимают больше места и отображают меньше элементов на экране.

Во время оформления запроса на обслуживание у вас есть возможность сохранить его в виде черновика для заполнения и отправки в другое время. Неотправленные запросы будут отображаться в виде черновиков в правой верхней части страницы.

## Использование рабочей зоны Каталога услуг

Используйте рабочую зону Каталога услуг для отправки запросов на обслуживание, сообщения о проблемах и создания инцидентов. В рабочей зоне Каталога услуг перечисляются все услуги, которые предлагаются вашей организацией.

Для просмотра и поиска предложений услуг можно использовать один из параметров:

- **Фильтровать по категории**: Выберите этот параметр в списке **параметров фильтрации**. Вы можете выполнять фильтрацию по подразделениям, элементам **Наиболее популярное** и **Избранное** (услуги, помеченные как избранные).
- **Поиск**: Введите ключевое слово в строке поиска и нажмите ВВОД для отображения записей, соответствующих ключевому слову.

### Использование избранного

В категории избранного вверху списка перечисляются все услуги, которые были добавлены в избранное.

- Для отображения всех услуг в избранном выберите параметр избранного **Параметры фильтрации**.
- Для добавления услуги в список "Избранное" в рабочей зоне Каталога услуг нажмите значок избранного - :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/TyBDqtrBJvviEbsNA9H0q_favorites-disabled.png" alt caption}. Изображение значка "Избранное" изменится на :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/PpUeoRqi6-vf-IaXNOstE_favorites-selected.png" alt caption}, и появится всплывающее сообщение о том, что выбранная услуга добавлена в список избранного, и эта услуга будет помещена в верхнюю часть списка вместе с другими услугами, уже добавленными в избранное.

<hint type="info">
  Функция "Избранное" доступна в портале \{\{FRS\_VARS.Self\_Service\_Mobile\_portal-Mobilnoe-prilozhenie-samoobsluzhivaniya}} только, если она была включена вашим администратором.
</hint>

<ExpandableHeading>
  ## Для создания запроса на обслуживание:

  1. Нажмите значок Каталога услуг :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/rIqh3dbYdudR-MMzPHsw-_servicecatalogicon.png" alt caption}.
  2. Нажмите раскрывающийся список вверху страницы для отображения доступных категорий. Для открытия этого списка на смартфонах вам может потребоваться коснуться значка фильтра в правом верхнем углу.
  3. Выберите категорию, а затем проведите пальцем по списку для выбора нужного предложения. Нажмите предложение, а затем **Запрос**. Отобразится форма.
  4. Заполните поля формы и нажмите **Проверить и отправить**.
  5. Проверьте точность информации и нажмите **Сохранить для дальнейшего использования**, **Отправить** или **Правка**. Сохранение для дальнейшего использования отображает запрос в виде черновика в правом верхнем углу страницы. Когда вы будете готовы, откройте и отправьте черновик.
</ExpandableHeading>

<ExpandableHeading>
  ## Для создания инцидента:

  1. Нажмите значок Каталога услуг :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/rIqh3dbYdudR-MMzPHsw-_servicecatalogicon.png" alt caption}.
  2. Нажмите раскрывающийся список вверху страницы, а затем **Сообщить о новом инциденте**. Для открытия этого списка на смартфонах вам может потребоваться коснуться значка фильтра в правом верхнем углу.
  3. Просмотрите перечисленные проблемы для выбора той, которая соответствует вашей проблеме. Нажмите проблему, а затем **Запрос**. Будет открыта форма.
  4. Заполните поля формы. Если она сконфигурирована, отобразится панель **Родственные элементы** со списком часто задаваемых вопросов и статей знаний, соответствующих вашей проблеме. Эти документы могут содержать решение, и если это так, нажмите **Разрешить**. Иначе закройте панель, заполните форму и нажмите **Сохранить инцидент**.
</ExpandableHeading>

<ExpandableHeading>
  ## Для обновления созданного инцидента:

  Чтобы помочь службе поддержки разрешить инцидент, вам может понадобиться добавить в него примечание или вложение. Вы можете сделать это только после регистрации инцидента. После добавления примечания или вложения они становятся постоянной частью записи инцидента, которую уже нельзя удалить.

  На устройстве iOS можно вложить только один элемент. В зависимости от конфигурации вашего приложения вы можете быть ограничены некоторыми типами файлов для вложения (например, .MOV).

  1. Нажмите значок :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/2kaK7rwVQeoFPRO_LLskE_myitemsicon.png" alt caption} для открытия списка **Мои элементы**. Появится список ваших открытых элементов.
  2. Найдите зарегистрированный инцидент и нажмите его для открытия.
  3. Для вложения файла или фотографии: в разделе **Вложения** нажмите **Обзор** для выбора файла. Выберите файл и нажмите **Сохранить**. Имейте в виду, что отображение вкладываемых файлов будет зависеть от установленных приложений или возможностей просмотра на вашем устройстве.
  4. Для добавления примечания: в разделе **Новые примечания** нажмите текстовое поле для ввода примечания. После завершения нажмите **Сохранить**.

  <hint type="info">
    **Вложение фотографии с помощью камеры устройства iOS**Настройки конфиденциальности на устройствах iOS, использующих браузер Safari, могут помешать вам использовать камеру. Камера будет открыта, но экран останется пустым, и будет доступна только кнопка отмены. В этом случае включите функцию камеры: **Настройки > Приватность > Камера** на вашем устройстве Apple. Откройте доступ к камере для приложения Safari.
  </hint>
</ExpandableHeading>
