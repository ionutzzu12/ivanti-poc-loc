## Запрос регистрации поставщика

Отправьте запрос для регистрации поставщика услуг или продуктов, которые он предоставляет.

**Для создания запроса регистрации поставщика:**

1. Выполните вход в портал самообслуживания \{\{Primary.Company}} Neurons.
2. Выберите **ИТ-услуги**, а затем **Каталог услуг**.
3. Выберите категорию **Общие услуги**, а затем **Регистрация поставщика**.
4. Для получения информации о выполнении запроса предложений Каталога услуг по умолчанию см. раздел :Link[Запрос регистрации поставщика]{label="Запрос регистрации поставщика" overridedLabel="Запрос регистрации поставщика" spaceId docId="6ihTxiVZ1cAo3xqXETkq_" version="v2" docAnchorId="#h3_Vendor_Onboarding_Request" loadingMethod="dynamic" newTab="false" href="Neurons-for-GRC-Self-Service-User.mdx"}.
5. Нажмите **Проверить и отправить**:
   - Если информация поставщика верна, нажмите **Отправить**.
   - Для дополнительных изменений нажмите **Правка**, выполните нужные изменения и повторите отправку.

После отправки запроса регистрации поставщика для утверждения элемент **Статус** будет отмечен как "Отправлено".

**Для просмотра отправленного запроса:**

1. Нажмите значок **Главная страница** в левом столбце.
2. Выберите **Мои элементы** на \{\{Primary.Company}}главной странице портала самообслуживания Neurons.
3. Выберите элемент в списке **Мои элементы**.
