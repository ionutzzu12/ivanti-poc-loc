Каждая рабочая зона портала самообслуживания обладает различными возможностями и используется для выполнения разных функций. Чтобы узнать больше о каждой из них и о задачах, которые вы можете выполнять как пользователь портала самообслуживания, откройте следующие ссылки:

- Просматривайте, обновляйте или закрывайте ваших отправленные запросы на обслуживание и инциденты. Для получения информации см. раздел [Мои элементы](my-items.mdx).
- Отправляйте новые запросы на обслуживание или создавайте инциденты. Для получения информации см. раздел [Запросы на обслуживание и инциденты](service-requests-and-incidents.mdx).
- Просматривайте статьи базы знаний, которые могут помочь при разрешении проблем. Для получения информации см. раздел [Центр знаний](knowledge-center.mdx).
- Просматривайте объявления, часто задаваемых вопросы и предупреждения, опубликованные в портале. Для получения информации см. раздел [Объявления, часто задаваемые вопросы и предупреждения](announcements-FAQs-and-alerts.mdx).
- Используйте форум для отправки и получения сообщений от других пользователей. Узнайте, как находить, фильтровать и удалять сообщения, а также настраивать группы пользователей для обмена сообщениями. Для получения информации см. раздел [Сообщения форума](social-board-messages.mdx).
- Общайтесь с другими, используя чат-зону с мгновенными сообщениями. Для получения информации см. раздел [Чат-зона](chat-zone.mdx).
