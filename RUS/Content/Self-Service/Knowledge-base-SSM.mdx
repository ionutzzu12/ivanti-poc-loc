Рабочая зона **База знаний** может использоваться для доступа ко всем статьям, доступным в Центре знаний, и поиска решений или информации о проблемах, с которыми вы столкнулись. В рабочей зоне отображаются самые полезные и последние статьи, призванные помочь вам устранить проблемы ваших запросов.

<ExpandableHeading>
  ## Чтобы пометить статью как избранную:

  Пометка информационной статьи помогает быстро найти наиболее упоминаемые статьи . Статьи, занесенные в избранное, отображаются вверху списка.

  В рабочей зоне Базы знаний нажмите значок избранного :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/TyBDqtrBJvviEbsNA9H0q_favorites-disabled.png" alt caption} для статьи Базы знаний.

  Изображение значка изменится на :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/PpUeoRqi6-vf-IaXNOstE_favorites-selected.png" alt caption}, а затем появится всплывающее сообщение о том, что выбранная статья Базы знаний помечена как избранная, и она будет перемещена в верхнюю часть списка для отображения вместе с существующими избранными статьями. Функция избранного доступна только, если она была включена вашим администратором.
</ExpandableHeading>

<ExpandableHeading>
  ## Для отправки отзыва на статью:

  Вы можете оценивать и давать отзывы для статей знаний.

  1. В меню рабочей зоны нажмите **База знаний**.
  2. Выберите статью для оценки.
  3. В разделе **Оценить эту статью** выберите количество звездочек, отражающих вашу оценку (одна - бесполезна, до пяти - "то, что я нужно"). Появится всплывающее сообщение о том, что ваша оценка для этой статьи отправлена.
  4. Нажмите **Да** или **Нет** для ответа на вопрос, "Эта статья была полезной?". Вы также можете добавить отзыв в разделе **Отзыв**.
  5. После ввода отзыва нажмите **Отправить отзыв**.
  6. Необязательно. Если вы хотите изменить свой отзыв, нажмите , сделайте необходимые изменения, а затем нажмите **Обновить отзыв**.

<ExpandableHeading>
  ## Для отображения статей знаний:

  1. Выполните вход в ПО Neurons for ITSM.
  2. В меню рабочей зоны нажмите **Статьи знаний**. Отобразится список статей знаний.
  3. Нажмите статью для просмотра ее информации.

  Для поиска конкретной статьи знаний введите ключевое слово в поле **Поиск** (верхний правый угол страницы) и нажмите клавишу ВВОД. Отобразятся результаты поиска.
</ExpandableHeading>

<ExpandableHeading>
  ## Для отображения с использованием фильтра и сортировки:

  1. Выполните вход в ПО Neurons for ITSM.
  2. В меню рабочей зоны нажмите **Статьи знаний**.
  3. Нажмите раскрывающийся список **Фильтрация и сортировка**. В раскрывающемся списке отобразятся варианты **Фильтровать по** и **Сортировать по**. Вариант **Сортировать по** может использоваться для отображения статей по возрастанию или убыванию и на основе данных заголовков, описаний, дат публикации и ключевых слов.
  4. Выберите вариант фильтрации и нажмите **Применить**. Будут отображены статьи знаний на основе ваших критериев фильтрации.
</ExpandableHeading>

<ExpandableHeading>
  ## Для отображения с использованием фильтра поиска избранного:

  1. Выполните вход в ПО Neurons for ITSM.
  2. В меню рабочей зоны нажмите **База знаний**.
  3. Нажмите раскрывающийся список **Все** и выберите избранные статьи знаний, созданные только для просмотра определенной информации.
</ExpandableHeading>
