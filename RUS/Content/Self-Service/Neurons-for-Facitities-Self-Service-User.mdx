Версия: 2022.4

\{\{FRS\_VARS.Company}} \{\{FRS\_VARS.Neurons\_for\_Facilities}} 2022.4 предоставляет пользователям портала самообслуживания расширенные функциональные возможности для их существующей системы \{\{FRS\_VARS.ProductName-Service-Manager}}.

После входа в \{\{FRS\_VARS.Company-short}} \{\{FRS\_VARS.ProductName-Service-Manager}} с установкой \{\{FRS\_VARS.Neurons\_for\_Facilities}} 2022.4 пользователи портала самообслуживания могут:

- Бронировать доступные места для конференций, рабочие помещения и кабинеты.
- Выбирать по несколько назначенных им производственных активов, которые они хотели бы взять с собой при переезде на другой объект.
- Функция запроса производственных активов улучшена для совершенствования и удобства взаимодействия с пользователем.

Все вышеперечисленные усовершенствования доступны в разделе описания Каталога услуг и услуг оснащения.

Для получения общих инструкций создания запроса на обслуживание см. раздел [Запросы на обслуживание и инциденты](service-requests-and-incidents.mdx).

Для получения информации обо всех функциях запросов, которые могут быть выбраны в Каталоге услуг, см. раздел [Предложения Каталога услуг по умолчанию](<../ServiceDesk/ServiceCatalog/Default Catalog Offerings.htm>).

Представленные далее функции запроса, являются новыми или улучшенными для \{\{FRS\_VARS.Company-short}} \{\{FRS\_VARS.Neurons\_for\_Facilities}} 2022.4.

## Запрос на перемещение сотрудника

Запрос на перемещение из одного объекта на другой, включая любые, назначенные запрашивающему, активы.

**Для создания запроса на перемещение сотрудника:**

1. В рабочей зоне **Главная страница** портала самообслуживания выберите **Другие услуги**.
2. Выберите категорию **Услуги оснащения**, а затем **Запрос на перемещение сотрудника**.
3. Для получения информации о выполнении запроса предложений Каталога услуг по умолчанию см. раздел :Link[Запрос на перемещение сотрудника]{label="Запрос на перемещение сотрудника" overridedLabel="Запрос на перемещение сотрудника" spaceId docId="Sa5DAzmd5jqsbtJ8-tojY" version="v2" docAnchorId="#h3_Employee_Move_Request" loadingMethod="dynamic" newTab="false" href="Neurons-for-Facitities-Self-Service-User.mdx"}.
4. После заполнения полей нажмите **Отправить**.

## Бронирование помещений

Бронирование конференц-зала, кабинета или помещения, включая доставку питания и необходимого оборудования.

**Для бронирования:**

1. В рабочей зоне **Главная страница** портала самообслуживания выберите **Другие услуги**.
2. Выберите категорию **Услуги оснащения**, а затем **Бронирование помещений**.
3. Для получения информации о выполнении запроса предложений Каталога услуг по умолчанию см. раздел :Link[Запрос на бронирование помещений]{label="Запрос на бронирование помещений" overridedLabel="Запрос на бронирование помещений" spaceId docId="Sa5DAzmd5jqsbtJ8-tojY" version="v2" docAnchorId="#h3_Facility_Reservation_Request" loadingMethod="dynamic" newTab="false" href="Neurons-for-Facitities-Self-Service-User.mdx"}.

**Для запроса актива оснащения:**

3.
