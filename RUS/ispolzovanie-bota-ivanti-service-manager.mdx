Вы можете использовать бот \{\{FRS\_VARS.Company}} Service Manager для выполнения нескольких действий, таких как создание инцидента, проверка статуса инцидента и чат с аналитиком.

1. Откройте бот \{\{FRS\_VARS.Company}} Service Manager и отправьте сообщение.

<hint type="info">
  Если бот вам недоступен, обратитесь к администратору вашей организации для его конфигурации.
</hint>

2. Выберите любой из следующих параметров.
   - **Создание инцидента** - используется для создания инцидентов.
   - **Проверить статус моего инцидента** - используется для отображения статуса всех открытых инцидентов.
   - **Чат с службой поддержки** - вы будете соединены с аналитиком, который поможет вам с вашей проблемой/запросом.
     - Если аналитик не ответит на ваш запрос в чате, вы получите сообщение - "Пожалуйста, подождите, пока мы соединяем вас с другим аналитиком" (Please stand by, while we connect you to another analyst). Вы можете подождать соединения.
     - Если нет активных аналитиков, вы получите сообщение- "Нет активных аналитиков" (All analysts are offline). Вы можете продолжать ожидать, пока аналитик не подключится к сети, или прекратить ожидание. Максимальное время ожидания соединения с аналитиком составляет 5 минут, после чего отображается следующее сообщение, - "Извините, мы не можем подключить вас в данный момент" (Sorry, we are unable to connect you at this time). Нажмите **Да** для продолжения использования бота или **Нет** для выхода.
   - **Покинуть чат** - выход их чата.
   - **Справка** - используется для отображения диалога с описанием представленных выше параметров.

<hint type="info">
  - Если вы отправите текстовое сообщение вместо выбора одного из указанных вариантов, отобразится следующее сообщение - "Неверный выбор. Выберите один из доступных вариантов" (Invalid selection. Please select one of the available option).
  - Каждый раз после отображения ботом параметров, нужно выбрать один из представленных вариантов. Иначе отобразится ошибочное сообщение, предлагающее выбрать только из отображенных вариантов.
</hint>
