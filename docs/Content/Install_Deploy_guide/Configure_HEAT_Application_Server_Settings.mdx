You set connections to other databases in \{\{Primary.Product}} on the Application Server Settings page. You will do the following:

- Specify the location of the configuration server and the host name.
- Specify if you will use this server for surveys or the reporting feature.
- If you use Windows Integrated Security for the Application Server, specify the Windows domain credentials for the service account.

*Application Server Settings Page*

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/yzXkkCTORWlcwRG_AVHKZ/mCtpWe5YqH7YiVGrbjvKO_applicationserversettings.png" position="flex-start" size="40" initialPath="Install_Deploy_Images/application_server_settings.png" githubPath="ITSM-On-Prem-Help/Content/Install_Deploy_guide/Install_Deploy_Images/application_server_settings.png"></Image>

1. Enter values into the fields:

| Parameter                     | Description                                                                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Configuration Server Location | The host name or domain name of the configuration server. The default value is the name of the server that you are logged into now.<br />If the host that you are logged into now is not the configuration server, enter the machine name or fully-qualified domain name of your Configuration Server.<br />If you check Use SSL below, you must enter the host name of the configuration server. |
| Port                          | The port number of the configuration server. The default is 80, or 443 if you check Use SSL.                                                                                                                                                                                                                                                                                                      |
| Use SSL                       | Check to use SSL for connections to the configuration server.<br />NOTE: We do not recommend enabling SSL on the configuration server until you have fully tested \{\{Primary.Product}} to ensure that it works with SSL. For information on configuring \{\{Primary.Product}} with SSL, see [Optional SSL Configuration](SSL_Config.mdx).                                                        |

2. Click Test Connection to test the connection to the configuration server. The system displays a success or failure message. Click OK to close the message.

4. If you are using Microsoft SQL authentication for the configuration server, the system displays this message: "Local system account will be used for IIS Application Pool Identity and Windows Service". See :Link[Service Account]{label="Service Account" overridedLabel="Service Account" spaceId docId="im47mKyMG_ilmmIbVvUa9" version="v2" docAnchorId="#HEAT_Service_Account" loadingMethod="dynamic" newTab="false" githubPath="Diff_Accounts_New.htm#HEAT_Service_Account" href="Diff_Accounts_New.mdx"} for more information about this account.

To use a different account, do the following:

<Paragraph indent="1">
  a. Check Use a different account.
</Paragraph>

<Paragraph indent="1">
  b. Click Set.
</Paragraph>

<Paragraph indent="1">
  c. Enter the user name for the service account.
</Paragraph>

<Paragraph indent="1">
  d. Enter the password associated with the service account.
</Paragraph>

<Paragraph indent="1">
  e. Click OK.
</Paragraph>

5. Each tenant in a multiple server deployment must have an administrator account. If you selected Multiple Server Deployment on the Configuration Application page, click Previous to return to the \{\{Primary.Product}} application page and create additional tenant accounts.
