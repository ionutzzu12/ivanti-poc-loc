To use the \{\{Primary.Product}} configuration database (called ConfigDB), you must log in first. Only administrators can log into the ConfigDB.

By default, the system displays a drop-down menu allowing you to choose either ConfigDB (the \{\{Primary.Product}} configuration database) or ISM (the \{\{Primary.Product}} application database).

If you do not see the Application drop-down menu, you must configure \{\{Primary.Product}} to show it.  For instructions on doing this, see the "Logging into \{\{Primary.Product}}" section of the Installation and Deployment Guide for \{\{Primary.Product}} .
