## Adding a New Feature

In \{\{Primary.Product}}, you can add features. An example of a feature is Google Analytics. Follow these steps to add a feature:

1. Log in to the ConfigDB.
2. From the workspace selector bar, click More....
3. Select Feature. The system displays the Feature workspace.
4. Click New Feature.
5. In the Feature Name field, enter a name for the feature.
6. Click Save.

## Changing the State of a Feature

Follow these steps to change the state of an existing feature.

1. Log in to the ConfigDB.
2. From the workspace selector bar, click More....
3. Select Feature Management. The system displays the Feature Management workspace.
4. Click New Tenant Feature.
5. Enter information into the fields:
   - In the Tenant field, enter or select the tenant that this feature applies to.
   - In the Feature field, select the feature.
   - In the State field, select a state from the drop-down list. You can choose from the following states: Unconditionally on, Trial period, Trial Completed, Disable.
6. Click Save.
